# 🍕 Pizza Sales Analysis

A quick slice of business insights from pizza sales data using Excel and SQL.

This project explores sales trends, product performance, and customer preferences through:
- A clean Excel dashboard for visual storytelling
- SQL-based data analysis and validation

It highlights when people order most, what pizzas sell best, and how order value shifts across the week.

🔗 Full details and visuals are available on my [portfolio website](https://saileshrana.github.io).
